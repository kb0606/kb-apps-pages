# Repository workflow

- Treat the GitHub `origin` remote as the shared repository. Check the current branch and working tree before making changes.
- Keep each commit focused on the requested work. Do not include unrelated pre-existing changes in a commit.
- When a requested change is complete, create a descriptive commit and push the current task branch to `origin` when the branch workflow permits it. Leave incomplete work uncommitted, and report clearly if a commit or push cannot be completed.
- Do not push directly to the default branch or rewrite shared history. Never force-push unless the user explicitly requests it.
