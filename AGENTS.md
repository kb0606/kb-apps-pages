# Repository instructions

## Public GitHub Pages content

- This repository contains public-facing static pages published with GitHub Pages. Treat every committed file, page, and asset as publicly accessible.
- Do not add secrets, credentials, or private information to this repository.
- Follow the site structure, localization, and asset guidance in `README.md` when editing pages.

## Git workflow

- GitHub is the source of truth for this repository. After completing any requested changes in this repository, create a descriptive commit and push it to the configured GitHub remote (`origin`) on the current branch before finishing the task.
- Before committing, inspect the working tree and stage only files changed for the current task. Keep unrelated or pre-existing changes out of the commit.
- Confirm that the push succeeded and report the commit hash when summarizing the work.
- Do not rewrite published history or force-push.
