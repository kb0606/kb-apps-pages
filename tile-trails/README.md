# Tile Trails 紹介ページのスクリーンショット

日本語と英語で同じ5画面を用意する。地図の2枚は同じ場所を表示し、モードによる違いがひと目で分かるようにする。残りの3枚で、記録中の操作、保存した記録の確認、開拓の成果を紹介する。

## 撮影リスト

| 掲載順 | ファイル名 | 撮影する画面と状態 | ページ内の掲載先 |
| --- | --- | --- | --- |
| 1 | `tile-map.webp` | Tileマップのタイルモード。複数の移動記録で訪れた場所が色の違う六角形で表示され、下部に移動距離・移動時間・通過Tile・踏破Tileが見える状態。 | `#tile-mode` |
| 2 | `exploration-map.webp` | Tileマップの開拓モード。1枚目と同じ中心・ズーム・向き・期間・アクティビティで、グレーの未探索エリアと地図が見える訪問済みエリアの境界を写す。 | `#exploration-mode` |
| 3 | `recording.webp` | 記録タブでGPS取得後の記録中。青い軌跡、記録中の表示、距離・時間・平均速度・獲得Tile、一時停止ボタンが見える状態。 | `#recording` |
| 4 | `session-detail.webp` | 履歴から保存済みの記録を開いた詳細。サンプルの記録名、出発・到着地点、全体のルート、統計が見える状態。 | `#history` |
| 5 | `exploration-achievements.webp` | 開拓モードの実績タブ。「最大連結開拓エリア」を選び、対象範囲の地図と面積を写す。開拓面積と一度の最大新規開拓面積も画面内に収める。 | `#achievements` |

地図の比較を優先し、最初に1・2を揃える。履歴一覧、開始前・一時停止中、設定、権限確認、ZIP操作は初回の掲載対象から外す。タイルモードの実績は本文で紹介する。

## 撮影と掲載

- 日本語・英語とも、公開対象と同じアプリ版・縦長のスマートフォン・ライトテーマ・同じ距離単位で撮影する。地図のモード変更で表示範囲がリセットされるため、比較画像は変更後に中心と縮尺を合わせ直す。
- 公園や河川敷など公開できる場所を使い、撮影用の端末またはプロファイルにサンプルの移動記録を用意する。複数のルートに重複区間と枝分かれを作ると、タイルの色分けと開拓範囲の両方を見せられる。実際の生活圏、個人名、通知、開発用UIの写り込みを確認する。
- Google Mapsのロゴと地図データの帰属表示を残し、ページ上の表示サイズでも読めることを確認する。[Googleの地理コンテンツ利用ガイドライン](https://about.google/brand-resource-center/products-and-services/geo-guidelines/)
- 原本は素材管理側の `tile-trails/raw/screenshots/{ja,en}/` に画面IDで保存する。WebPを `tile-trails/assets/{ja,en}/screens/` に配置し、通常のGit blobとして保存する。
- 画像が揃ったら、言語別ページの表にある各カードの末尾へ下の形式で追加する。画像へのリンクで原寸表示を可能にし、代替テキストと寸法は実際の画像に合わせる。狭い画面ではカードが縦に並ぶ。

```html
<a class="screen-image" href="../assets/ja/screens/tile-map.webp">
  <img src="../assets/ja/screens/tile-map.webp"
       alt="Tileマップ。訪れた場所を六角形のタイルで色分けし、下部に移動距離と時間などを表示"
       loading="lazy" decoding="async">
</a>
```
