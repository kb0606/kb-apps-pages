Tile Trails 隱私權政策

最後更新日期：2026年11月10日

Tile Trails（以下稱「本應用程式」）會記錄步行、跑步、騎自行車及開車等活動，讓您在地圖上查看移動路線與造訪過的六角形圖格。本政策說明本應用程式處理的資訊，以及與 Google 地圖等外部服務的通訊方式。

使用本應用程式不需要建立帳戶。

1. 本應用程式處理的資訊

活動記錄可能包含每個行程的開始與結束時間、活動類型、標題、暫停時間，以及 GPS 位置資訊（緯度、經度、記錄時間與位置精確度）。本應用程式會依據這些記錄計算距離、實際活動時間、速度及造訪過的 H3 六角形圖格等資訊。行程標題可能根據第一筆記錄位置的地名自動產生，且可由您編輯。

本應用程式也會在裝置上儲存語言、距離單位、自動停止及地圖顯示模式等設定。單純使用本應用程式不會使我們取得您的姓名、電子郵件地址或聯絡人。

2. 位置資訊的使用與權限

您開始一個活動行程後，本應用程式會使用位置資訊記錄路線和造訪過的圖格。記錄進行期間，即使本應用程式在背景執行，也可能持續取得位置資訊。暫停行程時會停止記錄位置；結束行程時則停止取得位置資訊。使用此功能需要作業系統授予精確位置與背景位置權限。

若您在沒有進行記錄時使用地圖的目前位置按鈕，本應用程式可能會取得您的目前位置以移動地圖中心。此位置不會儲存為路線記錄點。未授予位置權限時，無法使用活動記錄功能。

3. 資訊使用目的

我們使用相關資訊提供活動記錄、路線與地圖顯示、歷史記錄與統計檢視、造訪圖格計算、記錄編輯與刪除，以及備份建立和還原等功能。本應用程式提供者不會將活動記錄用於廣告或行為追蹤。

4. 儲存位置與伺服器通訊

活動記錄和位置資訊會儲存在您裝置上的 SQLite 資料庫；設定會儲存在本應用程式的本機設定空間。本應用程式沒有帳戶系統、由提供者營運的使用者資料伺服器或雲端同步功能。正常使用時，本應用程式不會自動將活動記錄或 GPS 歷史資訊傳送給提供者；提供者也未營運用來接收或儲存這些資料的伺服器。

Android 版本會停用 Android 雲端 Auto Backup。作業系統或裝置製造商提供的換機資料轉移功能，則依各提供者的功能與政策處理。

5. Google 地圖與外部服務

本應用程式使用 Google Maps SDK 顯示地圖，因此裝置需要與 Google 地圖伺服器通訊。Google 可能因此接收或記錄 IP 位址、裝置與作業系統資訊、本應用程式和 SDK 版本、請求時間，以及地圖互動資訊。Google 公開的 Android SDK 資料也提到 SDK 識別碼、當機資訊，以及移動或縮放地圖等互動。地圖請求可能顯示正在查看的區域；記錄活動期間若地圖跟隨目前位置，Google 可能據此推測您所在的大致區域。詳情請參閱Google Maps SDK 資料揭露說明及Google Maps Platform 資料處理說明。

本應用程式會使用儲存在裝置中的記錄，將路線和造訪圖格疊加在地圖上顯示，不會將完整活動歷史傳送到由本應用程式提供者營運的伺服器。不過，Google 可能會處理 SDK 地圖請求所涉及的地圖區域及其他資訊，以提供地圖服務。Google 對資訊的處理亦受Google 隱私權政策等規範約束。

本應用程式會使用作業系統提供的反向地理編碼功能，依據第一筆 GPS 位置建立行程標題。依裝置和作業系統而異，用來取得地名的座標可能會傳送給作業系統提供者或其他服務提供者；相關處理依該提供者的隱私權政策辦理。

6. 備份與還原

您可以自行操作，將已完成的行程匯出為 ZIP 備份，之後再匯入。備份可能包含行程日期與時間、活動類型、標題、暫停時間、GPS 座標、記錄時間及位置精確度。

備份檔會透過作業系統的儲存或分享功能，儲存到您選擇的位置。本應用程式不會自動傳送備份檔。由於備份包含位置歷史資訊，請妥善保管並謹慎分享。若您選擇雲端儲存空間或其他應用程式作為目的地，該服務的隱私權政策將適用。

7. 向第三方揭露

本應用程式提供者不會出售儲存在您裝置上的活動記錄，也不會為廣告目的提供給第三方。Google Maps SDK、作業系統的位置與反向地理編碼功能，以及您選擇的備份或分享服務提供者，可能會處理提供相關功能所需的資訊。除法律要求外，提供者不會主動將使用者資料另行提供給第三方。

本應用程式不包含由提供者營運的廣告或行為分析 SDK。Google Maps SDK 為營運地圖服務而處理的資訊如上所述。

8. 保存期間與刪除

活動記錄會保留在您的裝置上，直到您刪除為止。您可以在本應用程式中刪除個別行程，也可以透過作業系統的應用程式設定清除本機資料，或解除安裝本應用程式。

本應用程式無法刪除已匯出的備份檔，請自行從儲存位置刪除。正常使用本應用程式不會在提供者營運的伺服器產生活動記錄。Google、作業系統或您選用的服務所持有的記錄與資料，依各提供者的程序處理。

9. 安全性

本應用程式會將記錄儲存在裝置上專屬的應用程式空間，並使用作業系統提供的保護功能。但我們無法保證裝置或網路通訊絕對安全。備份檔包含位置歷史資訊，請謹慎選擇儲存位置及分享對象。

10. 兒童隱私

本應用程式並非為了刻意蒐集兒童的個人資訊而設計。

11. 本政策的變更

若本應用程式功能、資料處理方式或外部服務有所變更，我們可能更新本政策。最新版本會公布於本頁面。
