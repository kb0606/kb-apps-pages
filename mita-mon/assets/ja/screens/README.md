# Japanese landing page screenshots

The landing page at `mita-mon/ja/index.html` is designed around real app screenshots.

Expected files:

- `record-form.webp` — 新規記録画面。タイトル、日付、評価、感想、カテゴリ等が分かる状態
- `timeline-normal.webp` — 記録一覧（通常表示）
- `timeline-compact.webp` — 記録一覧（コンパクト表示）
- `timeline-thumbnail.webp` — 記録一覧（サムネイル表示）
- `timeline-grid.webp` — 記録一覧（画像グリッド表示）
- `detail.webp` — 記録詳細。画像、評価、感想等が見える状態
- `calendar.webp` — カレンダー表示。複数日に記録がある状態
- `highlight.webp` — ハイライト画面。KPI・カテゴリ・タグ等がある程度埋まった状態

## Capture guidelines

- Android実機の日本語UI
- 画面比率は同一端末で統一
- ステータスバーを含めるか除くかは全画像で統一
- 個人情報や実在人物のプライベート情報を含めない
- Web掲載時はWebPへ変換して配置
